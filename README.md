# project-manager

برنامه‌ی مدیریت پروژه‌های کاری (مثلاً «ساخت یک بازوی رباتیک»).

## امکانات

- **پروژه‌ها**: افزودن، تغییر عنوان و حذف پروژه از نوار کناری.
- **هر پروژه شامل تب‌های زیر است:**
  1. **مشخصات پروژه**: عنوان و تعریف/توضیحات پروژه.
  2. **برنامه‌ریزی**: لیست کارها با قابلیت تیک زدن کارهای انجام‌شده.
  3. **یادداشت‌ها**: ویرایشگر متن غنی (بولد، کج، زیرخط، خط‌خوردگی، تیتربندی، اندازه، قلم، رنگ نوشته، هایلایت، لیست، چینش متن و …).
  4. **هزینه‌ها**: نام هزینه + مبلغ، با جمع کل و واحد پول قابل تنظیم.
  5. **تقسیم کار**: کارها به‌همراه مسئول و وضعیت انجام.
  6. **اعضای گروه**: نام و نقش/تخصص هر عضو.
- **تب‌های دلخواه**: با عنوان دلخواه و نوع انتخابی (یادداشت، لیست کارها، هزینه، تقسیم کار، اعضا)، قابل تغییر نام و حذف.

اطلاعات در مرورگر (localStorage) ذخیره می‌شود؛ بنابراین با بازکردن مجدد همان مرورگر در دسترس است.

## اجرا

برنامه بدون نیاز به نصب هیچ پکیجی کار می‌کند. کافی است پوشه `app` را با یک سرور ساده اجرا کنید:

```bash
cd app
python3 -m http.server 8080
```

سپس در مرورگر به آدرس `http://localhost:8080` بروید.
